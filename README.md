# 💻 Bas Waaijer — VS Code Portfolio

Een interactieve portfolio website gebouwd als een **Visual Studio Code simulator**.
Navigeer door bestanden, open tabs, gebruik de terminal en verken wie ik ben als developer.

🌐 **Live:** [less-mess1.github.io/portfolio](https://less-mess1.github.io/portfolio)

---

## ✨ Features

- 🗂 Volledige VS Code UI — activity bar, sidebar, tabs, statusbar
- 📄 Vijf "bestanden" met echte content: `about.md`, `projects.json`, `skills.js`, `cv.md`, `contact.html`
- 🎨 Syntax highlighting per bestandstype (Markdown, JSON, JS, HTML)
- 📊 Animerende skill bars
- ⬛ Werkende terminal met eigen commands (`help`, `whoami`, `joke`, `sudo hire-bas`, ...)
- 🔍 Zoekfunctie via `Ctrl+F` of Edit → Find
- 🌗 Light/Dark mode toggle
- 📂 Sidebar toggle
- 📬 Contactformulier (vereist PHP server)
- 📱 Klikbare links naar GitHub, LinkedIn en email

## ⚡ Terminal commands

Open de terminal via **Terminal → New Terminal** of `View → Toggle Terminal`.

| Command | Wat het doet |
|---|---|
| `help` | Lijst van alle commands |
| `whoami` | Wie ben ik? |
| `skills` | Opent skills.js |
| `projects` | Opent projects.json |
| `contact` | Contactgegevens tonen |
| `git log` | Mijn leven in commits |
| `joke` | Random programmeer grap |
| `coffee` | Essentieel |
| `sudo hire-bas` | Belangrijkste command |
| `ls` | Bestanden bekijken |
| `clear` | Terminal leegmaken |

## 🚀 Lokaal draaien

```bash
git clone https://github.com/less-mess1/portfolio.git
cd portfolio
```

Open `index.html` direct in je browser. Voor het contactformulier heb je een PHP server nodig (bijv. XAMPP of Laravel Herd).
